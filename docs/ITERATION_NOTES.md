# 迭代说明

## 2026-08-11：系统配置与语音模型

- 左侧导航调整为：对话配置、记忆管理、功能列表、快捷能力、测试模块、系统配置。
- 系统配置拆分为“回复设定”和“模型配置”两个页签。
- 语音模型支持本地 CosyVoice 与 OpenAI 兼容 API 二选一，并可配置音色、语速和风格指令。
- 本地语音服务地址会透传到底层流式发送链路，且仅允许本机回环地址。
- API 语音会先生成临时音频再作为微信语音发送，发送结束后自动清理临时文件。

## 2026-08-11

- 新增“群聊仅在被 @ 或引用圆子时回复”开关；未触发的群消息仍进入会话上下文，不创建回复任务。
- 自动回复分段改为模型显式语义分段；普通换行和长文本不再按字符数强制拆成多个气泡。
- 回复生成期间继续轮询和接收其他消息，避免当前任务阻塞后续群聊上下文与并行任务入队。
- 左侧新增“配置”页，模型接口、回复策略和聊天参数从自动聊天页迁入；自动聊天页只保留会话接管、运行控制和工作状态。
- 移除 MyBot 主动点击微信“转文字”的 OCR、右键菜单和鼠标模拟链路。
- 语音识别改为依赖微信自身的“自动语音转文字”设置；程序只读取 UIA 控件名称中已经生成的文本。
- 移除 SDK 专用语音转写操作日志，避免后台轮询触发微信窗口和焦点变化。

使用前请在微信设置中开启自动语音转文字（设置名称可能随微信版本略有差异）。未开启时，程序会收到语音时长或“语音”占位文本，这是微信没有提供转写结果，不再由 MyBot 自动点击补救。
