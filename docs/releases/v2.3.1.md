# MyBot 2.3.1

本版本修复 Windows 覆盖安装时的进程关闭链路。

## 修复

- 手动双击安装包覆盖安装时，也会识别并停止正在运行的 MyBot 前端。
- 优先请求 MyBot 正常退出，超过等待时间后才强制结束。
- 通过 Qt 单实例锁、进程类型、启动时间与命令行共同校验目标，避免误结束无关 Python 进程。
- 无法停止旧版本时中止覆盖安装并显示明确错误，不再无限等待。
- 首次安装后的启动器会先应用安装向导选项并生成 `config.json`，再检查环境和启动 Server。
- 选择“稍后配置 API”时不再被环境检查阻止进入 MyBot 配置界面。
- 本地 WebSocket 可使用配置中的端口，不再被环境检查固定限制为 5177。

## 验证

- 覆盖安装继续保留 `config.json` 与 `data/`。
- 软件内更新仍使用显式 PID 完成退出、安装和自动重启。
- 手动覆盖安装、无关进程保护和显式 PID 关闭均有自动化测试。
- 安装后首次启动的配置生成链路有独立自动化测试。
- 延后填写 API 和自定义本地 WebSocket 端口均有环境检查测试。
