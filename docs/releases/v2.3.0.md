# MyBot 2.3.0

本版本开始提供 Windows 安装包，目标是让新用户无需手动复制 Codex CLI、编译 Server 或配置全局 Codex 环境即可部署。

## 主要更新

- 新增可选择安装目录和组件的 Windows 安装程序。
- 提供自包含微信 Server，并可选择内置 Python 运行环境。
- 安装时可选择功能列表/SDK 资源、快捷能力和 Codex CLI 扩展。
- 主模型 API 可在安装时配置，也可稍后在 MyBot 中填写。
- 新增每 10 分钟一次的 GitHub Release 版本检查和应用内更新提示。
- 点击更新后自动下载并校验安装包，停止旧程序，覆盖安装并启动新版本。
- Codex CLI 改为项目内可选扩展，可从 OpenAI 官方 Release 下载安装并使用独立 API 配置。

## Codex CLI

CLI 的运行文件、`CODEX_HOME`、会话与配置都保存在当前 MyBot 安装目录，不读取用户全局 Codex 配置。管理员仍可启用 YOLO 模式，普通联系人任务继续限制在独立任务工作区。

## 验证

- 安装包和 CLI 官方包均执行 SHA256 校验。
- 自动更新只接受当前 GitHub Release 中与版本号匹配的 x64 安装包。
- 离线测试覆盖版本比较、安装包校验、CLI 安装、路径穿越防护和项目内配置隔离。
