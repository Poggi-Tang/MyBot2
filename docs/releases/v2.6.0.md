# MyBot 2.6.0 Beta 1

This beta unifies MyBot's extensibility controls and removes the separate “快捷能力” concept from the interface.

## Highlights

- The feature window now contains exactly `功能列表 / MCP / Skill`.
- Automatically matched, validated abilities are displayed in the Skill page with triggers, validation and usage count.
- MCP and project Skills support import, removal, enable and disable controls using the supplied switch artwork.
- Built-in MCP servers and Skills remain protected from removal.
- Codex CLI receives only enabled MCP configurations and enabled Skills are synchronized into the project-local runtime.
- Imported command-based and URL-based MCP server definitions are supported.

## Validation

- Full Python regression suite: `330 passed, 8 subtests passed` before release synchronization.
- Release checkout regression suite and Windows installer build are run again for this tag.

This is a prerelease build. Back up project-local configuration and runtime data before installing over a production setup.
