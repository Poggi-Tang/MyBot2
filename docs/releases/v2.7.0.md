# MyBot 2.7.0 Beta 1

This beta release replaces the remaining conversation-monitoring path with a
Python UIA implementation and strengthens startup initialization, quoting and
message routing.

## Highlights

- Scans every visible conversation on the first successful connection and
  validates group/private metadata before automatic handling starts.
- Waits for WeChat's active title to match the selected conversation before
  reading messages, quoting or sending a reply.
- Retries transient UIA transitions without consuming unread-message state.
- Finds quote targets across message pages and selects WeChat's quote command
  through OCR-assisted context-menu handling.
- Adds one-click NewAPI configuration import and project-local model defaults.
- Adds MyBot-specific AutomationIDs plus the easyuiauto control Skill.
- Separates backend services, routing and conversation actions from the main UI.

## Fixes

- Missing or stale title controls no longer default conversations to private.
- Realtime acknowledgements and final replies no longer fail immediately while
  WeChat rebuilds the conversation panel.
- Rapid messages remain available for retry when a conversation has not loaded.
- Poetry, copywriting, plans and other non-visual creation requests no longer
  trigger image generation.
- Quote handling, attachment routing and restart recovery are more reliable.

## Validation

- Full offline regression suite: 435 passed, 22 subtests passed.
- Windows installer built from the tagged source and SHA-256 verified.

This is a prerelease build.
