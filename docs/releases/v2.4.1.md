# MyBot 2.4.1

本版本修复已有项目被错误提示“CLI 未安装”的兼容问题，并加入 Windows 原生 EXE 启动入口与系统托盘。

## 桌面体验

- 窗口、任务栏、系统托盘、快捷方式和安装包统一使用新的微信双气泡图标。
- 关闭主窗口后 MyBot 继续驻留系统托盘；点击托盘图标可恢复窗口，右键菜单提供“显示主界面”“重启”和“关闭”。
- 安装版通过无控制台的 `MyBot2.exe` 启动，不再让桌面和开始菜单快捷方式调用 `run.cmd`。

## 修复

- 优先识别新目录 `data/codex/runtime`。
- 新目录不存在时，继续识别当前项目原有的 `tools/codex` 完整 CLI。
- 兼容检测严格限制在当前 MyBot 项目内，仍不会读取 WindowsApps、全局 `PATH` 或全局 `CODEX_HOME`。
- 用户以后在模型配置中点击重新安装时，会自动切换到新的项目运行目录。

## 验证

- 旧项目 CLI 可直接恢复为已安装状态。
- 新旧目录同时存在时始终优先使用新目录。
- 缺少 CLI 的新项目仍显示未安装，并可通过界面从官方下载安装。
