# MyBot 2.5.0 Beta 1

这是吸附式桌面界面的首个 Beta 版本，重点验证微信伴随窗口、项目内 CLI 扩展、知识沉淀与语音链路。

## 吸附式桌面界面

- 原有重型主窗口拆分为状态、知识库、能力、MCP、Skill、设置六个独立窗口。
- 紧凑工具条自动吸附在微信顶部或底部中间，功能窗口优先吸附微信右侧，空间不足时切换到左侧。
- 使用 Windows DWM 可见边框计算，工具条和功能窗口与微信保持 0px 可见间距。
- 设置窗口与微信可见高度完全一致，并随微信移动、缩放和前台状态动态调整。
- 微信或 MyBot 在前台时显示；切换到其他程序、最小化或关闭微信时自动隐藏，切回微信后恢复原页面。

## 界面与交互

- 改为接近微信的白色、浅灰和绿色简约配色，标签背景自动继承所在面板。
- 下拉框、数值步进框、设置按钮统一使用项目 SVG/PNG 图标。
- 托盘右键菜单提供显示、重启和关闭，并补充清晰的悬浮及按下反馈。
- 基础人设改为多行文本框，适合填写身份、性格、关系和长期行为规则。
- 页面切换不再同步读取 CLI、记忆或 Skill；实测切换热路径约 0.42ms/次。
- 系统配置新增“关于”页，集中展示产品、版本、Beta 通道、GitHub 项目地址和更新检测。

## CLI、MCP 与 Skill

- Codex CLI 作为可选扩展由 MyBot 下载并保存在项目内，不依赖用户全局安装和配置。
- 模型、API、`CODEX_HOME`、权限、会话和任务数据保持项目隔离。
- MCP 页面展示实际可用工具，Skill 页面展示项目 Skill 与任务匹配能力。
- 增加独立开发的 `autowx` MCP 与 `autowx-strategyd` Skill 源码；本 Beta 不自动启用该 MCP。

## 知识、语音与安全

- 按人物和日期保存对话摘要、事实、偏好、上下文、附件及工作文件。
- CLI 可读取项目内历史知识和人物工作区，用于连续任务处理。
- 语音支持本地/API 模型、音色列表、Nora 参考音频与 Higgs 情绪/节奏表演规划。
- 管理员权限控制桌面截图、真实文件路径和 API 密钥等敏感能力。

## 自动对话可靠性

- 快速连续消息逐条进入任务队列，不再只保留最后一条。
- “语音播报”等明确请求由首轮回复决策直接路由到语音工具。
- Server 异常恢复时保留自动对话开关、队列、任务和会话状态，并等待 WebSocket 重连后发送。
- CLI、MCP 和外部进程发送的消息写入共享回声记录，避免被监听器误判为新的入站任务。

## Beta 说明

- 本版本以 GitHub Pre-release 发布，建议先在测试微信账号和独立安装目录中验证。
- 覆盖安装会保留 `config.json`、`data/` 和项目内 CLI 数据。
- 发现吸附、窗口焦点、语音或自动回复问题时，请附上操作步骤和 `logs/` 中对应时间段信息。

## 验证

- 自动化测试覆盖窗口吸附、前台显示、托盘、CLI 安装、语音、记忆、消息监听和页面切换。
- 安装包附带独立 SHA256 文件，下载后可校验完整性。
