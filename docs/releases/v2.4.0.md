# MyBot 2.4.0

本版本将 Codex CLI 调整为完全按需安装的项目扩展。

## CLI 扩展

- Windows 安装包不再携带 Codex CLI，也不再在安装向导中显示 CLI 组件。
- 进入“系统配置 → 模型配置 → Codex CLI 扩展”后，可点击“安装 CLI”。
- MyBot 从 OpenAI 官方最新 Release 下载 Windows x64 完整包与 Responses 代理，校验各自官方 SHA256 后再启用。
- 安装完成后才开放 CLI 的 API 地址、模型、密钥、推理强度、超时和管理员 YOLO 配置。
- CLI 运行文件、`CODEX_HOME`、任务、会话与 API 配置全部保存在当前 MyBot 项目中。
- CLI 启动时忽略用户全局配置，显式加载 MyBot 的模型、MCP、Skill 和权限参数，因此不依赖用户是否安装过或配置过全局 Codex CLI。

## 安装与兼容性

- GitHub Release 安装包不再预下载约 370 MB 的 CLI 扩展，下载和安装更轻量。
- 覆盖升级继续保留 `config.json` 与 `data/`，已安装的项目内 CLI 及其配置不会丢失。
- 修复英文 Windows 控制台在首次应用中文安装状态时可能导致启动失败的问题。

## 验证

- CLI 官方包下载地址、SHA256 校验、项目内原子安装和路径安全检查有自动化测试。
- 安装包不包含 CLI 组件或运行文件的策略有独立回归测试。
- 项目内 API、`CODEX_HOME`、`--ignore-user-config`、MCP 和权限参数均由调度测试覆盖。
