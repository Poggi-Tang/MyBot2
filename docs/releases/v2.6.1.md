# MyBot 2.6.1 Beta 1

This beta patch simplifies the compact toolbar's runtime status presentation.

## Changes

- The first navigation button is now labeled `运行` instead of using a colored status dot.
- The Run button opens tasks, connection information and tests as a normal navigation control.
- Connection and task state no longer recolor the Run button.
- Queued, working and sending tasks continue to appear as dynamic colored cells in the task container below the toolbar.
- The task container remains hidden when no tasks are active.

## Validation

- Full application regression suite passes before release.
- The Windows installer is rebuilt and verified for this tag.

This is a prerelease build.
