# MyBot v2.1.0

发布日期：2026-08-11

## 重点更新

- 新增“系统配置 → 安全管理”，支持按微信联系人名称配置管理员。
- 桌面截图、真实绝对路径、API 密钥、访问令牌、密码、隐私信息和他人历史对话仅对管理员开放。
- 群聊管理员身份只按实际发送者判断，群名称不会继承管理员权限。
- 非管理员的敏感请求会在进入模型、实时工具和 Codex CLI 前被拦截；文字、语音及成果文件发送前增加二次脱敏。
- 管理员 Codex CLI 可使用 YOLO 模式；非管理员自动关闭 YOLO、使用独立任务目录，并与管理员 Codex 线程完全隔离。

## 语音能力

- 语音模型支持本地 CosyVoice 与 API 两种来源。
- 新增 Boson 语音 API 支持，可从 `/v1/audio/voices` 获取音色列表。
- 支持选择音色、语速与风格指令，并修复 API 语音返回 400 的请求兼容问题。
- API 音频发送完成后自动清理临时文件；本地语音服务仅允许回环地址。

## 对话与记忆

- 左侧导航统一为：对话配置、记忆管理、功能列表、快捷能力、测试模块、系统配置。
- 系统配置拆分为回复设定、模型配置和安全管理三个页签。
- 新增按联系人和日期组织的工作区，自动记录每日收发对话、任务结果及关联文件。
- 个人记忆、情景记忆与每日工作区可供任务上下文和后续知识沉淀使用。
- 群聊支持在任意位置识别 `@圆子` 或引用消息，未触发的消息只进入上下文、不创建回复任务。
- 回复生成期间持续接收新消息，提升对话检测、任务入队和同会话并行效率。

## Codex 与任务执行

- 支持 Codex CLI YOLO 参数 `--dangerously-bypass-approvals-and-sandbox`。
- 改进任务状态、附件解析、成果文件交付、CLI 线程复用和失败回退。
- 非管理员任务不加载项目快捷能力，也不会在项目根目录执行快速文本任务。
- 任务生成文件按敏感级别过滤，避免配置、凭据或截图文件发送给非管理员。

## 修复与改进

- 修复表情包连续发送限制：仅限制 AI 连续发送，用户消息会正确打断连续状态。
- 修复表情包动作误触发截图快捷键的问题。
- 改进微信消息监听、发送者识别、引用识别和自动聊天启动恢复。
- 语音识别改为读取微信自动转文字结果，不再主动模拟点击“转文字”。
- 附件测试与真实微信下载目录隔离，避免本机新文件干扰自动化测试。

## 验证

- 源码完整测试：228 passed，4 subtests passed。
- 稳定发布目录测试：223 passed，4 subtests passed。
- 已验证 MyBot 桌面客户端正常启动并连接，WebSocket 与语音服务保持运行。

## 升级说明

- `config.example.json` 新增 `voice`、`personal_memory`、`security` 和 `codex.yolo_mode` 配置示例。
- 实际 `config.json` 不会进入版本库；升级后请在“系统配置”中保存本机模型密钥、语音配置和管理员名单。
- 建议至少配置一名管理员后再启用自动聊天。
