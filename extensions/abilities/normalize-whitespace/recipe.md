# Whitespace Normalizer

## 适用条件

当需要离线清理文本文件中的连续空格、制表符或换行，并将结果保存为另一个文件时使用。输入与输出路径必须由调用方提供。

## 输入

- `--input`: 必填，待处理的 UTF-8 文本文件路径。
- `--output`: 必填，写入规范化文本的路径；可与输入不同。

## 命令

```text
python scripts/normalize_whitespace.py --input <输入文件> --output <输出文件>
```

## 输出

输出文件使用 UTF-8 编码；所有连续空白字符被替换为一个 ASCII 空格，并移除文本首尾空白。标准输出报告写入位置。

## 依赖

Python 3.9+，仅使用标准库；不需要网络或外部服务。

## 失败处理

缺少参数、输入不存在、输入无法按 UTF-8 解码或输出不可写时，命令以非零状态退出并给出错误信息。先修正路径或编码后重试；不会覆盖输入文件，除非调用方明确将同一路径同时作为输入和输出。
